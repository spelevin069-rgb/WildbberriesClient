# WildbberriesClient — новый лаунчер на базе Refract

Эта ветка изолирована от основной ветки `main`. Текущий проект в `main` не меняется.

## Как получить Windows EXE

1. Скачай подготовленный архив `WildbberriesClient-Launcher-Windows-Build.zip` из чата.
2. На GitHub открой ветку **refract-launcher**.
3. Нажми **Add file → Upload files** и загрузи архив, назвав его **source.zip** в корне ветки.
4. Нажми **Commit changes**. Сборка Windows запустится автоматически.
5. Открой вкладку **Actions**, дождись завершения задачи **Build new WildbberriesClient Refract launcher**.
6. Внизу успешного запуска скачай **WildbberriesClient-Windows-x64**. Внутри будут установщик и EXE.

Если сборка завершится ошибкой, пришли скрин вкладки Actions с красным шагом — по журналу можно будет исправить причину.
