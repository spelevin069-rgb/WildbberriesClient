# Публикация установщика через GitHub

После настройки пользователь скачивает только `WildbberriesInstaller.exe`. При запуске установщик обращается к последнему публичному GitHub Release, скачивает `WildbberriesClient-Bundle.zip`, устанавливает клиент в `%LOCALAPPDATA%\WildbberriesClient`, сохраняет существующую папку `run`, создаёт ярлык и запускает лаунчер.

## 1. Создай GitHub-репозиторий

1. На GitHub создай **публичный** репозиторий с именем `WildbberriesClient`.
2. Загрузи в него всё содержимое этой папки `wildbberries` (именно содержимое, не ZIP-файл).
3. Открой `bootstrapper/Program.cs` и замени:

   `YOUR_GITHUB_USERNAME/WildbberriesClient`

   на `ТВОЙ_ЛОГИН/WildbberriesClient`.
4. Сохрани изменения и отправь их в GitHub.

## 2. Создай релиз

На своём компьютере в папке репозитория выполни:

```bat
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions автоматически соберёт лаунчер, сформирует ZIP-пакет клиента и скомпилирует самостоятельный `WildbberriesInstaller.exe`, затем прикрепит оба файла к Release.

## 3. Что скачивает пользователь

Пользователь открывает GitHub → Releases → последний релиз → скачивает только `WildbberriesInstaller.exe`. Остальное установщик загружает сам.

## Требования и замечания

- Репозиторий должен быть публичным, иначе загрузчик без токена не сможет получить релиз.
- В Windows-установщике используется .NET 8 self-contained: отдельная установка .NET не нужна.
- Для запуска самого Minecraft-клиента может потребоваться его собственная версия Java.
- Перед публикацией проверь права на распространение всех файлов внутри `ClientPayload.zip`.
- Если публикуешь новый клиент, увеличь версию тега и создай новый Release.
